GIT REFLECTION

1. Git is used for: Tracking file changes and keeping a history of a project.
2. GitHub is used for: Hosting Git repositories online and collaborating with others.
3. A commit means: A saved snapshot of staged changes in the local repository.
4. A branch is used for: Working on changes separately before merging them into main.
5. A Pull Request is used for: Proposing and reviewing changes before merging branches.
